## 화면 구성 (위에서 아래로)

### 1. 머리줄
- 제목 "푸리 재무", 기간 설명 한 줄.
- 기간 버튼 7개: 오늘(기본), 어제, 7일, 30일, 이번 달, 지난 달, 전체.
  - 7일, 30일은 **어제까지** 완료된 날(오늘 제외)입니다.
  - 이번 달은 1일부터 오늘까지, 지난 달은 지난달 1일부터 말일까지, 전체는 2026-01-01부터 오늘까지입니다.
  - 고른 버튼을 표시합니다(aria-pressed).
- 날짜 직접 입력(시작, 종료)은 남깁니다. 머리줄에 들어가지 않으면 기간 버튼 옆 작은 입력칸으로 둡니다.
- 시딩과 브랜딩 포함 스위치(지금 기능 그대로), 새로고침, 테마 전환, 로그아웃.
- 다른 세션의 `feat/pnl-page`가 머리줄에 '월별 P&L' 링크를 넣습니다. 그 브랜치가 먼저 머지되면 링크 자리를 남깁니다.

### 2. 손익 카드 6장 (`KpiStrip` 대체)
- 순서: 결제매출, 광고비, 결제수수료, 리포트 원가, MER, 공헌이익. 공헌이익 카드만 테두리를 초록 계열로 강조합니다.
- 카드 한 장: 이름, 큰 숫자(만 원 단위, 10만 미만은 소수 한 자리), 비교 한 줄, 보조 한 줄.
- 보조 줄
  - 결제매출: "부가세 제외 X, 결제 N건"(부가세 제외는 `totals.revenueExVat`)
  - 광고비: "메타 X, 네이버 Y"(스위치를 켜면 시딩, 브랜딩도)
  - 결제수수료: "매출의 x.x%"
  - 리포트 원가: "결제 1건당 N원"(리포트 원가 ÷ 결제 건수, 서버비가 있으면 "서버비 포함")
  - MER: "전체 매출 ÷ 광고비"
  - 공헌이익: "마진 x.x%"
- 비교 줄
  - 완료된 기간: 지금처럼 이전 같은 길이 기간 대비(일평균 비교 로직 그대로). 매출, MER, 공헌이익은 오르면 초록, 내리면 빨강. 비용 카드 3장은 색 없이 회색.
  - 오늘: 결제매출만 "어제 같은 시각 대비"로 비교합니다. 어제 결제의 시간대별 금액(`/api/payments?from=어제&until=어제`의 `hourly`)을 지금 시각까지 더해 씁니다(지금 시간대는 분 비율로). 나머지 카드는 "진행 중"으로 씁니다. MER 비교 줄은 "진행 중이라 판정 안 함".
- 스파크라인은 없앱니다.

### 3. 광고 판정 (`ChannelSection`의 히어로와 채널 표 대체)
- 한 카드 안에 왼쪽 판정, 오른쪽 캠페인 표. 좁으면 위아래로 쌓습니다.
- 카드 머리 오른쪽 칩: 7일 이상이면 "실제 돈 확인 N%"(지금 계산 그대로, 90~110% 초록, 밖이면 빨강). 7일 미만이면 회색 "실제 돈 확인은 7일 이상 볼 때".
- 왼쪽
  - "메타 ROAS" 큰 숫자(`cur.pixelRoas`), 이전 기간 대비 %p.
  - 손익분기 막대: 0~200%, 손익분기 위치에 세로선과 "손익분기 N%" 이름.
  - 판정 칩: 손익분기 +5%p 이상 "증액 가능"(초록), 0~5%p "유지"(노랑), 아래 "감액 검토"(빨강). 아이콘과 글자를 같이 씁니다.
  - 아래 세 칸: 광고비(메타), 공헌이익(메타 기준, 캠페인 합), 마지막 클릭 ROAS(`cur.metaRoas`, 회색).
- 오른쪽 캠페인 표
  - 열: 캠페인(짧은 이름 + "마지막 클릭 결제 N건"), 광고비, 메타 ROAS(가로 막대 + 손익분기 세로선 + 값), 판정, 공헌이익(`contributionProfitAtRoas`), 마지막 클릭 ROAS, CTR, CPM, 일 예산.
  - CTR, CPM, 일 예산은 `/api/dashboard/meta-campaigns`를 `campaignId`로 붙입니다. 아래쪽 'Meta 캠페인 운영 지표' 표는 없앱니다.
  - 광고비 0원 줄(캠페인 불명 등)은 표에서 뺍니다. 맨 아래 '메타 전체' 합계 줄.
  - 공헌이익 식 한 줄 설명을 표 아래에 둡니다.
- 오늘 보기
  - 큰 숫자 옆 비교 대신 "HH:MM 기준", "하루 동안 계속 바뀝니다".
  - 판정 칩 대신 회색 "진행 중인 날이라 판정하지 않습니다". 캠페인 표 판정 칸은 회색 "진행 중".
- 신규 고객 보기 토글, aMER, nCAC 카드, 채널 표(채널·캠페인별 성과)는 없앱니다.

### 4. 매출에서 이익까지 (새 카드, '비용 구조' 대체)
- 제목 아래 큰 글씨: "결제 100원 중 X원이 남습니다". 오늘이면 뒤에 "(진행 중)". 공헌이익이 음수면 "결제 100원당 X원 손실입니다".
- 100원 막대 하나: 세금과 비용(부가세 + 결제수수료 + 리포트 원가, 회색), 광고비(주황), 남는 돈(청록). 아래 범례에 "N.N원".
- 계산서 표: 열은 기호, 계산, 금액, 100원당.
  - 결제매출
  - − 부가세
  - = 부가세 제외 매출 (굵게, 위 줄선)
  - − 결제수수료
  - − 리포트 원가
  - − 광고비
  - = 공헌이익 (남는 돈) (굵게, 연한 청록 바탕)
- 숫자는 `totals`(스위치에 맞는 쪽)의 netRevenue, vat, revenueExVat, pgFee, reportCost, adSpend, contributionProfit을 그대로 씁니다.
- 아래 한 줄: 스위치가 꺼져 있으면 "시딩과 브랜딩 비용(X)은 빠져 있습니다. 켜면 공헌이익 Y"(`totalsWithMarketing` 차이). 켜져 있으면 "광고비에 시딩 X, 브랜딩 Y가 들어 있습니다".

### 5. 매출 출처 (`ChannelSection`의 비중 막대와 일별 채널 차트 대체)
- 부제: "결제 N건이 마지막으로 들어온 경로".
- 위에 묶음 표시: 메타 + 검색 + 미귀속을 "메타 광고 영향 X (N%)"로 괄호 모양 선과 함께.
- 100% 가로 막대(0원 채널은 생략). 순서: 메타, 검색, 미귀속, 자사 SNS, 레퍼럴, 인플루언서, 검색광고.
- 아래 표: 색, 이름(작은 설명), 금액, 비중, 건수. 7개 채널을 모두 적되 0원이면 회색.
- 맨 아래 한 줄: "검색과 미귀속은 메타 광고비를 따라 움직여서 메타 ROAS에 들어가 있습니다(9/4~11/12 상관 0.97)."
- 색: 레퍼럴은 분홍에서 보라로 바꿉니다(자사 SNS 청록과 색약 구분 실패, ΔE 1.6). 바꾼 뒤 인접 쌍이 모두 통과하는지 dataviz 검사기(`validate_palette.js`)로 라이트와 다크 둘 다 확인합니다. 인플루언서와 검색광고 색도 인접 쌍이 통과하게 정합니다.

- **기본 기간 '오늘'은 PR B에서 바꿉니다.** PR A 시점에는 옛 채널 성과가 남아 있어서, 오늘 보기에서 실제 돈 확인 숫자와 캠페인 판정 칩이 보입니다. 오늘 보기 처리가 들어가는 PR B와 같이 바꿔야 실패 기준에 걸리지 않습니다. PR A는 기본 7일(어제까지)로 둡니다.
- **오늘이 들어 있는 여러 날 기간(이번 달 등)의 비교는 지금처럼 '바로 앞 같은 길이 기간'입니다.** 대신 비교 줄에 "이전 14일 대비"처럼 비교 기간 길이를 씁니다. 지난달 같은 날짜와 비교하려면 광고 판정 쪽 서버 계산과 Mixpanel 조회를 늘려야 해서 이번에는 하지 않습니다.
- `app/layout.tsx`의 글꼴과 전역 색을 바꾸면 다른 세션의 P&L 페이지(`feat/pnl-page`, 미커밋)도 같이 바뀝니다. 바탕색과 글꼴만 바뀌는 수준이라 그대로 갑니다.
